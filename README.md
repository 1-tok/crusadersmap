# Outremer: the Crusader States, 1095 to 1571

Hand-drawn map of the Eastern Mediterranean for print, 36 x 48 in portrait (10800 x 14400 px at 300 dpi), in parchment and full colour editions.

## Contents
- Python source for the map: terrain, ridges, symbols, lettering, key and sources panels, print and SVG builders.
- data/ - Natural Earth layers, terrain tiles and the Jerusalem panel source image.
- fonts/ - fonts used for lettering.
- previews/ - preview images of both editions.
- print/ - 300 dpi print JPGs and Printify SVGs (under 20 MB each) for both editions.

## Rebuild
    python3 build_stage2.py 0.35 colour,parchment   # preview
    python3 make_base.py 0.8 colour                  # colour wash base
    python3 make_print.py 1.0 colour                 # base JPG and 300 dpi print file
    python3 make_light.py 1.0 colour 72              # picture JPG and lettering SVG
    python3 assemble_light.py colour                 # Printify SVG

Repeat with `parchment` for the second edition. Intermediate files (print/*.npy, ink and text SVGs) are not stored; they are regenerated by the scripts.

## Latest build (colour edition), 9 Nov 2026

Rebuilt with the newest artwork on the asset branches: 65 catalogue sprites (`assets/sprites`, built from `data/sprites/catalog.json` by `build_sprite_assets.py`, one preferred variant per site), the 32-piece terrain kit plus the dry-zone strips (`assets/terrain`), and the Dutch map's fine painted wave field for the sea (`assets/sea/field`, laid as in its `sea_fine_v62.py`).
Sprites are pushed inland so their building footprint stays dry (harbour water may overlap the sea); terrain pieces stay on land; labels that do not fit are tilted, curved or led out with a thin line.
Known gaps: 24 symbols still lack room (Saphet, Toron des Chevaliers, Chrysopolis, Chalkedon, Pera and others), the key panel still shows the older drawn symbols, Belvoir is a shrunk placeholder, and the parchment edition has not been rebuilt.
Print files: `print/Outremer-36x48-300dpi-colour.jpg` (10800 x 14400) and `print/Outremer-36x48-printify-colour.svg` (18.5 MiB).
