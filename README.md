# Outremer: the Crusader States, 1095 to 1571

Hand-drawn map of the Eastern Mediterranean for print, 36 x 48 in portrait (10800 x 14400 px at 300 dpi), in parchment and full colour editions.

## Contents
- Python source for the map: terrain, ridges, symbols, lettering, key and sources panels, print and SVG builders.
- data/ - Natural Earth layers, terrain tiles and the Jerusalem panel source image.
- fonts/ - fonts used for lettering.
- previews/ - preview images of both editions.
- print/ - 300 dpi print JPGs and Printify SVGs (under 20 MB each) for both editions.

## Rebuild
    python3 build_stage2.py 0.35 colour,parchment   # preview
    python3 make_base.py 0.8 colour                  # colour wash base
    python3 make_print.py 1.0 colour                 # base JPG and 300 dpi print file
    python3 make_light.py 1.0 colour 72              # picture JPG and lettering SVG
    python3 assemble_light.py colour                 # Printify SVG

Repeat with `parchment` for the second edition. Intermediate files (print/*.npy, ink and text SVGs) are not stored; they are regenerated by the scripts.

## Content manifests

[data/manifests](data/manifests/README.md) inventories every explicit active place, event, road and terrain definition, with proposed landmarks, named landscape overlays and route corridors. JSON retains structured metadata and geometry; CSV and a complete Markdown catalog support review. Rebuild with `python3 build_manifests.py` (standard library only).
## Sprite library

See [data/sprites](data/sprites/README.md) for nine transparent city/castle assets, source paintings, placement metadata and historical review flags. Rebuild with `python3 build_sprites.py` (Pillow, NumPy, SciPy). A light/dark comparison is in [previews/sprite-library.jpg](previews/sprite-library.jpg).

## Period-informed sprite candidates

[Batch 01](data/sprites/historical-1180/README.md) contains new Jerusalem and Belvoir interpretations for circa 1180, with evidence notes and remaining uncertainties. Jerusalem uses twice the standard display width. Rebuild packaging with `python3 build_historical_sprites.py`; see [light/dark preview](previews/historical-batch-01.jpg).

## Mountain terrain pieces

[data/terrain](data/terrain/README.md) contains 29 transparent regional mountain and connector stamps spanning Palestine, Lebanon, Anatolia and Greece, with source images, generation prompts and placement guidance. Rebuild using `python3 build_terrain.py`. See [terrain preview](previews/terrain-library.jpg).
