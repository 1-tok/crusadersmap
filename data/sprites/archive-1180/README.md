# Crusader States Sprite Library — circa 1180 AD

A portable set of illustrator sprites for the Crusader Map project. Generated in this ChatGPT thread; not independently committed to GitHub by this package creation.

**Placement policy:** `APPROVED_FOR_PROVISIONAL_PLACEMENT` can be used for a circa-1180 map, subject to historical/technical QA. `PERIOD_EXCLUDED_1180` must not be displayed for that year.

The first eight sites are the initial major centers/castles. The new coastal batch includes Tyre, Sidon, Caesarea and Jaffa; Tortosa and Arqah are included from an expansion plate. Montfort and Château Pèlerin/Atlit have a later construction date and are excluded from the 1180 view.

## Asset QA

Original sheet sprites and standalone fortresses are RGBA. Some newly generated coastal assets were rendered over an opaque checkerboard; background removal is approximate and may need refinement. The labeled poster is reference art only, not a map-ready atlas.
