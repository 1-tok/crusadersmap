# Generic Batch 13 filler sprites

69 individual transparent PNG sprites from sheets A and B. All are approved for **manual visual review placement** but are not associated with named sites or invented geographical coordinates. Review suitability of church forms, flags, buildings, terrain, coastline, rivers and transparency before placing them at any individual map point.

**Deliberately excluded:** `map_fillers_set_a-010.png`, a later bastioned star/artillery fort. The full source A sheet contains that fort and is not committed to this repository. The source B painting is stored as two lossless split PNG halves in `data/sprites/intake/2026-11-11/source_sheets/`.

Production renderer must not treat review-placement approval as final historical or 300-dpi certification.
