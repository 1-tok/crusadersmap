# Large natural landmark sprites

[Placement and naming manifest](placements.geojson). Coordinates are WGS84 longitude and latitude. The point marks the named feature within the painting. Register the feature itself against the point when compositing. Nominal widths are starting values for the 10,800 px print sheet, equivalent to about 140–225 px at period-preview scale.

The paintings use an elevated view from the south looking north. Add names as separate map lettering. Composite landscape art above the terrain wash and below settlement art, routes and text. Keep the existing coastline and waterways as geographic controls and review the footprint against nearby sites before enabling it in a map build. Records outside the current frames are reserved for future coverage.

NAT-L013–NAT-L016 reserve the IDs and placements described in the Natural Site Sprites conversation. The original artwork was unavailable, so these records have no PNG file. NAT-L017–NAT-L019 are new transparent illustrations. They and their proposed placements are available for review. This manifest is independent of the settlement catalog and the published map renderer.
